Keys

    
The fast loop: listen, then A or R. With autoplay on, the next line starts by itself.

    

      
Space
Play / pause the current line (images: open large)

      
↓J
Next item

      
↑K
Previous item

      
A
Accept, then advance

      
R
Reject, then advance

      
U
Back to pending

      
←→
Previous / next take, when a line was rolled more than once (Accept keeps the one you are on)

      
1–9
Go to take N and play it

      
0
Play what the game has now (the file this one would replace)

      
W
Lessons: what every review so far says about the prompts

      
E
Edit the line text for the re-roll (Enter saves and marks rejected, Esc cancels)

      
N
Add or edit a note (Enter saves, Esc cancels)

      
P
Toggle autoplay next (audio and video)

      
V
Show / hide the video behind an item (a GIF or poster frame with an mp4); on a video item, view it large

      
L
Loop videos on / off (check that a loop has no visible jump)

      
Z
View large: the image, or the video (Esc closes)

      
F
Finish review: counts, then Install accepted / Redo rejected (1–9 runs one)

      
O
Open / close the run log

      
HomeEnd
First / last item

      
?
This help

    

    
Esc to close
