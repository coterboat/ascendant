# Codex production notes

- Image tool: OpenAI built-in `image_gen` tool, default model path.
- Method: every final image was generated separately as a PNG using the named round-one/round-two faction images as visual references. The final assets were copied into this seat folder and visually checked for composition, faction continuity and absence of visible text.
- The capital slots deliberately paint lived-in places rather than isolated fortress kits. The model sheets emphasize strategy-camera silhouettes; the Candlewake melt preserves one fortress and camera across all three stages.
- A transient network error interrupted the last batch after three successful renders; only the missing Veiled Table slot was retried.
- Strongest image: `veiled_table_key.png`. The relief map, taut marigold cords, copper bowls, many arriving witnesses and simultaneous distant campaigns make the faction's prediction fantasy readable without UI or written labels.
