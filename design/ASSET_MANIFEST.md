Asset builder generates rows marked `spec` only when their ticket asks for them (M1 rows: #10). Style blocks, anchors, sizes, formats, gates and Ludo params are in `design/STYLE_BIBLE.md` §4–§6.

Status values: `spec` (written, not yet asked for) · `requested` (asset builder may generate) · `in-pr` (in an open asset PR) · `done` (made and accepted) · `rejected` (with a note).

Rules for every row:
- Send the prompt verbatim: style block first, then ` Subject: …`.
- `art_style: Cel-Shaded`. `augment_prompt: false` on stills and edits.
- In `tools/ludo/manifest.json`, set `"style": false` **and** `art_style` on every entry.
- Ids and request ids start with `asc_`. Bump `v` after any cancel or prompt change.
- **Candidates, raw masters, `__pycache__/` and `.env*` stay gitignored and are never committed.** There is no `.gitignore` on `main` yet, so #10's PR should add one.
- Every `generateWithStyle` sends its anchor as base64 from `assets/_anchors/` (Ludo URLs expire after 7 days).
