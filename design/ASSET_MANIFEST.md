# ASCENDANT: asset manifest

Status: **DRAFT.** Owner: art lead. One row per asset. Asset builder generates only rows marked `spec` or `requested`, and only after they're approved. Style blocks, sizes, formats and Ludo params per class are in `design/STYLE_BIBLE.md` §4–§5.

Status values: `spec` (written, not yet asked for) · `requested` (asset builder may generate) · `in-pr` (in an open asset PR) · `done` (merged) · `rejected` (with a note).

Rules for every row: the prompt is sent verbatim (style block first, then ` Subject: …`), `augment_prompt: false`, `"style": false` in `tools/ludo/manifest.json` so ludo.py doesn't append its global style, and ids start with `asc_` (ludo.py's `request_id` prefix is still `concurrent-`). Candidates are kept gitignored. Only the pick ships.

No milestone is defined yet. When this was written, `origin/main` had no `design/GAME_BRIEF.md`, no `design/MILESTONES.md` and no GitHub issues or milestones. The only brief is the director's unpushed draft (`e7f84ce`, awaiting Alex's approval). So this manifest has **only the probe rows**. Production rows get added once the director publishes milestone 1 and its tickets, and once Alex has picked a direction.

What the draft brief implies milestone-level art will need (not specced yet, no ids, no credits):
- **Map:** terrain textures for the final terrain list (proposed 10: plains, farmland, forest, hills, mountains, swamp, waste, tundra, sea, deep sea). Map icons: fort, temple, laboratory, throne, plus any site types the director adds.
- **Province state and HUD glyphs** (hand-written SVG, not Ludo): 7 slot emblems, 8 unit class glyphs, contested, siege, capital, and resource glyphs (gold, gems per magic path, population, supply, recruitment).
- **Army token ring** frame (code-drawn or one UI asset).
- **UI chrome:** main panel, tooltip panel, button (normal/hover/pressed/disabled), top resource bar, turn-report panel, end-turn button, codex link underline style.
- **Units:** national units and commanders per nation (brief: 4–6 nations, curated rosters). Count waits on the director's nation design. Static 256×256 only until a battle-playback milestone exists.
- **Portraits:** pretender chassis (count TBD) and national commanders.
- **Spell icons** per curated spell list, tinted per magic path (path palette TBD).
- **Item icons** if items are in milestone 1.
- **Audio:** UI click and hover, end turn, turn resolved sting, battle report open, recruit, move order, spell cast (one per path), one map ambience, main map theme, battle-report theme.
