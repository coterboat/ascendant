# ASCENDANT: asset manifest

Status: **DRAFT v2.** Owner: art lead. One row per asset. Asset builder generates only rows marked `requested` (or probe rows once Alex OKs the probe). Style blocks, sizes, formats and Ludo params per class are in `design/STYLE_BIBLE.md` §4–§7.

Status values: `spec` (written, not yet asked for) · `requested` (asset builder may generate) · `in-pr` (in an open asset PR) · `done` (merged) · `rejected` (with a note).

Rules for every row:
- The prompt is sent verbatim (style block first, then ` Subject: …`), with `augment_prompt: false` on still images.
- Set `"style": false` in `tools/ludo/manifest.json`, so ludo.py doesn't append its global style.
- Ids start with `asc_` (ludo.py's `request_id` prefix is still `concurrent-`).
- Candidates stay gitignored; only the pick ships.
- Animation rows always send `crop: false` and `frame_size: -9`.
